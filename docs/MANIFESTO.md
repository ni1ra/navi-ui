# Navi UI Manifesto

Navi UI is lain's reusable frontend system for expressive, production-grade interfaces across frameworks and products. It must make a coherent visual language easier to build than a pile of one-off components.

## Ideal

- A blueprint-driven theme contract that can produce materially different themes without forking component code.
- Three first-class reference themes: deep black, bright silver, and blood red.
- Elegant modern interaction with playful motion, rich but balanced density, and strong navigation primitives.
- Framework-portable design tokens and a first-class React package.
- Accessible defaults, responsive behavior, reduced-motion support, and complete interaction states.
- A stable, documented `v1.0.0` used by Dartio `v1.0.0` before wider adoption.

## Non-goals

- Copying generic component-library aesthetics.
- A card-grid generator or a theme made from scattered literal colors.
- Carrying code from any legacy Dartio repository.
- Speculative adapters without a current consumer.
